# คลังเมนูไทยสี่ภาค

เว็บหาไอเดียทำอาหารไทย 507 เมนูจาก 7 กลุ่มภาค ค้นได้จากเนื้อสัตว์ รสชาติ และวัตถุดิบที่มี แต่ละเมนูมีวิธีทำและข้อห้ามแยกระดับ

## ภาพประกอบ

- ภาพหลักของแต่ละเมนูดึงจากวิกิพีเดียภาษาไทยตอนเปิดเว็บ ถ้าไม่พบจะแสดงภาพวาดแทน
- แกลเลอรี "การจัดจานหลากหลายแบบ" ในหน้ารายละเอียด ดึงจาก Wikimedia Commons และ Openverse ซึ่งรวมภาพ Creative Commons จาก Flickr และคลังภาพเปิดอื่น
- ทุกภาพยังเป็นลิขสิทธิ์ของเจ้าของภาพตามสัญญาอนุญาตที่ระบุไว้ กดที่ภาพเพื่อดูต้นฉบับและเครดิตเต็ม

## ใส่ภาพของคุณเอง

- **วิธีที่ง่ายที่สุด:** อัปโหลดภาพไว้ในโฟลเดอร์ `images` และตั้งชื่อไฟล์ตามชื่อเมนูในเว็บ เช่น `images/ข้าวซอยไก่.jpg` (ใช้ .png หรือ .webp ก็ได้)
- **ใช้ลิงก์ภาพจากเว็บอื่น:** เพิ่มชื่อเมนูและลิงก์ภาพลงในไฟล์ `photos.json` ตามตัวอย่างในไฟล์ ใส่ชื่อผู้ถ่ายและลิงก์ต้นทางได้
- ภาพที่คุณใส่เองจะแสดงก่อนภาพจากวิกิพีเดียเสมอ ในหน้ารายละเอียดของแต่ละเมนูมีขั้นตอนพร้อมชื่อไฟล์ที่ต้องตั้ง

## สถานะข้อมูล

รายละเอียดสูตรเป็นร่างที่ยังไม่ได้ผ่านผู้รู้ตรวจทาน และยังไม่ได้ระบุแหล่งอ้างอิง

## เปิดใช้ GitHub Pages

Settings → Pages → Source: Deploy from a branch → Branch: `main`, โฟลเดอร์ `/ (root)`
